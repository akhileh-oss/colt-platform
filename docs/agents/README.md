# Agent documentation

One document per agent, added when the agent is built (Milestones 10–21). Each must record
purpose, input and output schemas, allowed and forbidden tools, model policy, prompt versions,
failure modes and its evaluation suite (`CLAUDE.md` §12.1, §110).

The cross-cutting design lives in
[`../architecture/AGENT_ARCHITECTURE.md`](../architecture/AGENT_ARCHITECTURE.md).
